# Pocket FM Telegram Bot

### Quick Deployment
1. Unzip the package:
   ```bash
   unzip pocketfm_bot.zip
   cd pocketfm_bot
   ```
2. Make `setup.sh` executable and run it:
   ```bash
   chmod +x setup.sh
   ./setup.sh
   ```
3. Test your bot on Telegram:
   - Send `/start`
   - Send `/search <show name>`
